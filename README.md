# Шахматы на четверых (2 на 2)

Браузерные шахматы для четырёх игроков на доске-кресте 14×14. Две команды:
**красные + жёлтые** против **зелёных + синих**, союзники сидят друг напротив друга.
Играется с компьютера и телефона, онлайн по ссылке или вчетвером на одном устройстве.

## Что внутри

- Полные правила четырёхсторонних шахмат: ход по часовой стрелке, союзников бить нельзя.
- Взятие короля выбивает игрока: его фигуры остаются на доске как нейтральные препятствия.
  Команда проигрывает, когда теряет оба короля.
- Пешки идут к противоположному краю и превращаются в ферзя.
- Онлайн-мультиплеер по коду комнаты (публичный ntfy.sh: HTTP + Server-Sent Events, без своего сервера и аккаунтов).
- Доска автоматически поворачивается: своя армия всегда снизу. На телефоне — тоже.
- Адаптивная вёрстка, управление касанием, журнал ходов, перезапуск партии.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173).

Быстрый просмотр без сети: откройте `http://localhost:5173/?demo=1` — партия на четверых за одним устройством.

Проверки:

```bash
npm test     # тесты движка
npm run build
```

## Как играть с друзьями

1. Откройте игру и введите имя, нажмите **Создать комнату**.
2. Скопируйте ссылку (**Пригласить**) и отправьте двум друзьям — они войдут в ту же комнату.
   Или продиктуйте код комнаты: его нужно ввести во вкладке **Войти по коду**.
3. Когда все в комнате, хост нажимает **Начать игру**.
4. Ходят по очереди: красные → зелёные → жёлтые → синие.

Можно начать и вдвоём: армии пустых мест убираются, вы играете 1 на 1 на большой доске.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите проект:

   ```bash
   git init
   git add .
   git commit -m "Шахматы на четверых"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/chess4.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Готово. Workflow `.github/workflows/deploy.yml` сам соберёт и опубликует игру
   при каждом пуше в `main`. Ссылка появится в разделе Pages и в логе запуска.

Сборка использует относительные пути (`base: './'`), поэтому работает и в подпапке
`https://ник.github.io/chess4/`.

## Правила коротко

| Что | Как |
| --- | --- |
| Команды | Красные + жёлтые против зелёных + синих (противоположные углы) |
| Очередь хода | По часовой стрелке, выбывшие пропускаются |
| Взятие | Только фигуры соперников; союзников и свои — нельзя |
| Король | Взяли короля — игрок выбывает, его фигуры становятся нейтральными |
| Победа | Команда, потерявшая обоих королей, проигрывает |
| Пешки | Один шаг вперёд, два с исходной линии, взятие по диагонали, превращение в ферзя на дальнем краю |

Рокировки и взятия на проходе нет — в четырёхсторонних шахматах они не применяются.

## Технологии

- React 18 + TypeScript + Vite
- Онлайн через публичный ntfy.sh: хост держит авторитетное состояние партии,
  гости присылают только свои ходы и получают обновления мгновенно (SSE).
  Свой сервер, WebSocket и аккаунты не нужны.
- Vitest для тестов движка

## Ограничения

- Комнаты идут через публичный сервис ntfy.sh: любой, кто знает код комнаты, может
  подсмотреть партию. Для игры с друзьями этого достаточно — не публикуйте код в открытых чатах.
- Если ntfy.sh недоступен или блокирует запросы, онлайн не заведётся (локальная игра работает всегда).
- Комната живёт, пока открыта вкладка хоста.
- Игра не хранит партии на сервере: истории и рейтингов нет.

## Структура

```

  game/     движок: доска, геометрия креста, правила, тесты

```
